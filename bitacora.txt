Roles:

HTML: es la estructura y contenido. Define qué hay en la página: títulos, secciones, imágenes, enlaces y formularios.
Ejemplo: la sección de catálogo de bicicletas.

CSS: estilos. Define cómo se ve la estructura: colores, tipografía, espaciado.
Ejemplo: dar identidad visual al encabezado y al botón de compra.

JavaScript: interacción y comportamiento. Define qué pasa cuando el usuario actúa: clics, formularios, animaciones.
Ejemplo: un filtro que muestra solo bicicletas de una categoría al hacer clic.

========================================================================
Justificación de 3 elecciones de tipo de campos en formulario de reserva
========================================================================

1- Para el campo de "Nombre completo" se uso type text, ya que el usuario debe digitar texto de forma libre.

2- Para el campo de "Plan" se uso type radio, con la finalidad de que el usuario solo pueda elegir una opción 
de forma mutuamente excluyente.

3- Para el campo de "Tipo de recorrido" se uso una lista de selección (select), con el fin de mostrar varias 
opciones y no ocupar mucho espacio ya que tenian un texto considerable.
