========================================================================

2- Para el campo de "Plan" se uso type radio, con la finalidad de que el usuario solo pueda elegir una opción 
de forma mutuamente excluyente.

3- Para el campo de "Tipo de recorrido" se uso una lista de selección (select), con el fin de mostrar varias 
opciones y no ocupar mucho espacio ya que tenian un texto considerable.

===================================
Propieades heredadas y no heredadas
===================================

Se analizo un párrafo y se pudo observar que desde el body se hereda el tipo de fuente
y su grosor. Y no se hereda el color de fondo de la página.


La clase "activo" no se aplica, porque existe una regla mas especifica que 
involucra a un ID, por ende se le da prioridad al ID. 

Clase activo

.activo {
    color: var(--verde-ruta); 
    font-weight: 600; 
}

ID 

#menu a { 
    color: var(--gris-asfalto); 
}

Como se observa, el ID = "menu" además de ser un ID, tiene mayor especificidad que
la class = "activo"

Selector        | Especificidad | 
----------------|---------------|
#menu a         | (1,0,1)       |
.activo         | (0,1,0)       |

A esto se le dio solución dandole más especificidad a la regla de "activo" de esta forma:

#menu a.activo {
    color: var(--verde-ruta); 
    font-weight: 600; 
}

=========================
Decidir si Grid o Flexbox
=========================

*Portada (inicio):
Grid (1fr 1fr)

Permite dos columnas de igual ancho con alineación vertical independiente. Con Grid se resuelve en una línea; con Flexbox tendría 
que pelear con align-items y flex: 1.


*Galería de rutas
Grid (repeat(3, 1fr))

Siempre 3 tarjetas en una fila. Grid define las columnas directamente; no necesito que se adapte a la cantidad.


*Reservas (layout 2:1)
Grid (2fr 1fr)

Proporción fija entre formulario y aside. Grid con fr es lo más directo para 2:1.


*Fila del formulario (documento + celular)
Flexbox (flex: 1 en cada campo)

Dos elementos en una fila. No necesito controlar filas Y columnas, solo repartir el ancho horizontal. Flexbox es más fácil en este caso.


*Encabezado (portada-top)
Flexbox (space-between)

Me permite colocar un elemento a la izquierda y otro a la derecha en una sola línea.


*Pie de página
Flexbox (space-between + align-items: flex-start)

Tres bloques en fila, alineados por arriba. No se necesita controlar filas y columnas a la vez.


Uso Grid cuando necesito controlar filas Y columnas o proporciones fijas (fr).
Flexbox es más util cuando solo necesito alinear elementos en una dirección (fila o columna).

Ajuste de errores
=================

360 px
La tabla de tarifas se desborda: el encabezado "Medio día (4h)" no cabe y obliga a scroll horizontal.

PAra intentar solucionarlo cambié el texto del <th> a "Medio día" sin "(4h)" y agregué word-wrap: break-word en los th y td para 
que las palabras largas se rompan en vez de forzar el ancho.


360 px
El botón de WhatsApp tapa el último párrafo del footer al llegar al final de la página.

Lo solucione aumentando el padding-bottom en el body de 80px a 90px y reduje el tamaño del botón: padding: 10px 16px y font-size: 0.85rem.


768 px
Cuando se activa .portada-top en row, el título "Rueda Libre - Tarifas" y los 3 enlaces del menú quedan muy pegados, sin espacio entre ellos.

Entonces agregué flex-wrap: wrap y gap: var(--espacio2) en .portada-top dentro de la media query de 768px, para que si no caben, el menú baje 
a la siguiente línea con separación.

===============================
Conflictos al incluir Bootstrap
==============================

1. Color de los enlaces del menú
Conflicto: Bootstrap establece un color predeterminado para los enlaces, mientras que el 
CSS propio define un color personalizado mediante el selector #menu a.

Solución: Se conserva el color personalizado de la página, ya que tiene mayor especificidad
y corresponde a la identidad visual del proyecto.

2. Tipografía de los encabezados
Conflicto: Bootstrap proporciona estilos predeterminados para los encabezados, pero el 
CSS propio establece la fuente Montserrat y un peso de 700 para los títulos.

Solución: Se mantuvo la tipografía personalizada para conservar la identidad visual de 
Rueda Libre y se verificó su presentación en diferentes tamaños de pantalla.

3. Tamaño del título principal
Conflicto: La regla header h1 establece un tamaño de fuente de 3 rem para pantallas de 1200 
píxeles o más, modificando el tamaño predeterminado de Bootstrap.

Solución: Se conservó esta personalización para escritorio y se revisó que el título mantuviera 
una proporción adecuada en pantallas pequeñas.
