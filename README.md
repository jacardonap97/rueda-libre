# Rueda Libre 

Este es un proyecto de una página web para un negocio de alquiler de bicicletas y recorridos por Medellín.

## ¿Qué tiene la página?

- Página de inicio con información del negocio.
- Secciones con diferentes bicicletas.
- Carrusel con promociones.
- Información sobre los recorridos.
- Página con las tarifas.
- Formulario para realizar reservas.
- Diseño responsive.

## Tecnologías utilizadas

- HTML
- CSS
- Bootstrap 5
